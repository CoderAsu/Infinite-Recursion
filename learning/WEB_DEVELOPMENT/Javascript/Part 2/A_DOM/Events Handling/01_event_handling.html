Event handling

  1. Listen for events with addEventListener()
  2. The event object: type, target, and currentTarget
  3. Event propagation: bubbling and capturing
  4. Stop a browser's default action with preventDefault()
  5. Handle many children with event delegation
  6. Remove listeners and use listener options
