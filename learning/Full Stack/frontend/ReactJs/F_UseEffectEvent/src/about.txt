Component Life Cycle

In simple words, a React component has three major lifecycle phases:
1. Mounting – Component is created and displayed.
2. Updating – Component re-renders when its state or props change.
3. Unmounting – Component is removed from the DOM.



// Mounting Phase
Mounting is the first phase of a component's lifecycle.
It happens when React creates a component and inserts its output into the DOM.

useEffect(() => {
    console.log("Component mounted");
}, []);





// Updating Phase
Updating happens whenever a component needs to render again.

useEffect(() => {
    console.log("Count updated:", count);
}, [count]);




// Unmounting Phase
Unmounting happens when a component is removed from the DOM.

useEffect(() => {
    console.log("Child mounted");

    return () => {
      console.log("Child unmounted");
    };
}, []);






useEffectEvent() is a React Hook that allows you to access the latest state and props inside an Effect-related callback without making the Effect re-run whenever those values change.

It is used in:
    -> Timer
    -> Auto-save
    -> WebSocket
    -> API Polling
