COMMIT HISTORY

git log --> to see the commit details
git reflog --> Keeps a local history of changes to HEAD and branch references, helping recover lost commits after operations like git reset
git show <commit_id> --> displays the details of a specific commit, including its commit message, author, date, and the changes (diff) introduced by that commit.

git log -n number -> to see how many commit
git log --oneline --> to see the commit_id with commit_msg in short
git log --oneline --all --> to see the commit_id with commit_msg of all branches
git log --oneline --all --graph
git log --pretty=short
git log --pretty=full
git log --pretty=fuller
git log --pretty=oneline
git log --pretty=format:"%h" --> to see only commit_id in short
git log --pretty=format:"%s" --> to see only commit_msg
git log --pretty=format:"%an" --> to see only author name
git log --pretty=format:"%ae" --> to see only author email
git log --since="1 week ago"
git log --since="date" --until="date"
git log --author="name"
git log --grep="modified"
