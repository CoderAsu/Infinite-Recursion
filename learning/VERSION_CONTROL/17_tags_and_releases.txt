TAGS AND RELEASES

A tag is a named reference to a specific commit. Tags are commonly used to mark releases such as v1.0.0.

git tag --> list local tags.
git tag v1.0.0 --> create a lightweight tag at the current commit.
git tag -a v1.0.0 -m "Release 1.0.0" --> create an annotated tag with a message (recommended for release tags).
git show v1.0.0 --> inspect the tag and tagged commit.
git push origin v1.0.0 --> push one tag to the remote.
git push origin --tags --> push all local tags to the remote; check them before using this.
git tag -d v1.0.0 --> delete a local tag.
git push origin --delete v1.0.0 --> delete a remote tag.

A hosting-site release (for example, a GitHub release) is usually created from a pushed tag and may include release notes or downloadable files. The tag is Git; the release page is provided by the hosting site.
